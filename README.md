# 소리길: 게임형 청각 재활 앱

인공와우·보청기 사용자가 집에서 매일 하는 청능훈련을 게임으로 만들고, 치료사가 원격으로 진도를 보는 앱입니다. 경진대회 출품용 시제품입니다.

## 실행
온라인 주소: https://l91326537-spec.github.io/project/ (main에 병합하면 자동 배포, 휴대폰에서 홈 화면에 추가 가능)

설치나 서버 없이 `web/index.html`을 브라우저로 열면 됩니다. 마이크 녹음은 `https://` 또는 `localhost`에서만 동작하므로, 로컬에서는 아래처럼 띄우는 걸 권장합니다.

```
cd web && python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 지금 되는 것
### 소리길 지도: 생활 장소 7곳을 차례로 오르는 사다리
| 장 | 장소 | 칸(10문제 한 판) | 관문(장면 15문제) |
|---|---|---|---|
| 1 | 우리 집 | 소리 알아차리기(순음), 집 안 소리 2개 중 고르기, 길이가 다른 낱말, 부르는 말 | 누가 불러요(조용함) |
| 2 | 동네 | 생활 소리 4개 중 고르기, 같은 길이 낱말, 낱말 따라 말하기 | 버스 타기(버스 소음 +12dB) |
| 3 | 시장·마트 | 첫소리만 다른 낱말, 받침·모음이 다른 낱말, 짝 낱말 따라 말하기 | 계산대(시장 소음 +12dB) |
| 4 | 병원·약국 | 생활 문장, 한 낱말만 다른 문장, 문장 속 헷갈리는 낱말 | 진료실(병원 소음 +12dB) |
| 5 | 카페 | 카페 소음 +12 → +9 → +6dB | 주문하기(카페 +5dB), 넘으면 **생활 깃발** |
| 6 | 식당·모임 | 식당 소음 +2 → 0dB | 가족 모임(식당 0dB) |
| 7 | 전화·TV | 곧 열려요 | 곧 열려요 |

- **칸 통과**: 10문제 중 8개 이상인 날이 서로 다른 날 2번(1·2장은 1번)이면 통과. 한 번 넘은 칸은 다시 잠기지 않음. 같은 칸에서 두 판 연달아 5개 미만이면 다음 한 판은 한 칸 아래 문제로 다지고 다시 돌아옴.
- **관문**: 그 장의 칸에서 한 번도 안 나온 문제 15개(말로 대답하는 문제 포함), 12개(80%) 이상이면 다음 장이 열림. 하루 3번까지. 2주 넘게 도전해 70%를 넘으면 다음 장을 열어 둠. 칸을 다 넘기 전에 관문부터 도전해도 되고, 넘으면 그 장의 칸은 모두 통과로 침(건너뛰기).
- **장 화면**: 칸 목록과 통과까지 남은 것, 관문 카드, 앱 밖에서 해 볼 생활 미션, 그 장소에서 쓰는 듣기 요령 카드. 아직 문항이 없는 칸은 '곧 열려요'.
- **판 결과**: "10문제 중 N개 맞혔어요"와 통과 상태, 틀린 문제마다 정답·고른 것·소음 속에서를 다시 들어 보는 버튼. 별·불꽃·점수·축하 효과는 없음.
- **오늘의 연습**: 집 화면 버튼 하나로 3판(8~10분)을 이어서 함. 지금 칸, 관문이나 따라 말하기(또는 약한 소리), 넘은 칸 복습. 3일 넘게 쉬었으면 복습부터. 숙제가 있으면 숙제 칸을 차례로.

### 함께 쓰는 기능
- **소리**: 순음은 500~4000Hz 적응형(맞히면 작게), 생활 소리 8가지 합성, 소음은 식당·카페·버스·병원·시장 장면을 합성(여러 사람 말소리, 그릇·기계 소리, 엔진, 계산대 삑 소리 등). 관문의 대화 장면은 낮은 목소리와 높은 목소리가 번갈아 말함.
- **가족 목소리**: 가족이 낱말·부르는 말·문장을 녹음하면 그 목소리로 출제(없으면 AI 음성이나 기기 음성).
- **취약음 분석과 맞춤 출제**: 틀린 답을 자모 단위로 비교해 "첫소리 ㅅ↔ㅆ"처럼 헷갈린 소리를 집계하고, 낱말·문장 칸에서 그 소리가 든 문제를 더 자주 냄. 약한 소리만 모은 연습도 있음(칸 통과에는 안 셈).
- **따라 말하기**: 들은 말을 소리 내어 따라 하면 음성 인식 결과를 자모 단위로 비교해 일치도와 다르게 들린 소리를 보여 줌. 2-5·3-5 칸은 5개 중 4개 이상 또렷한 날을 통과한 날로 셈. 음성 인식이 없는 브라우저는 녹음해서 정답과 나란히 들어 봄.
- **기록**: 연습한 날, 전체 판 수, 넘은 관문, 장별 진도, 최근 14일 맞힌 문제, 높낮이별 가장 작은 소리, 자주 헷갈린 소리.
- **월간 듣기 점검**: 늘 같은 20문제(단어 8, 문장 6, 소음 속 문장 6)로 달마다 점수를 견줌.
- **치료사·보호자 리포트**: 한눈에 보기(지금 장과 칸, 넘은 관문, 점검 변화 등), 하루 정답률, 칸별 처음→최근, 약한 소리, 높낮이별 결과, 메모. A4 한 장으로 인쇄·PDF 저장.
- **선생님 숙제**: 선생님용 화면에서 장별 칸과 관문, 하루 분량, 주 며칠, 전할 말을 고르면 숙제 링크와 QR이 만들어짐. 서버 없이 링크에만 담김(QR은 `web/qr.js`에서 직접 만듦). 예전 단계 숙제 링크도 칸으로 바꿔 읽음.
- **환자 기록 모아 보기**: 보호자가 보낸 기록 파일 여러 개를 열어 한 줄씩 봄(마지막 연습일, 이번 주, 지금 장·칸, 넘은 관문, 최근 정답률, 약한 소리, 월간 점검). 예시 환자 4명.
- **시연용 예시 기록**: 실제 통과 규칙으로 하루 3판씩 4주쯤 연습해 5장 카페까지 온 사람의 기록을 채우고, 끄면 원래 기록으로 돌아감. 예전 단계 기록은 처음 열 때 칸 기록으로 옮김.

기록과 녹음은 모두 사용자 기기(localStorage, IndexedDB)에만 저장됩니다.

## 문항과 음성
- 문항은 `web/content.js`에 모여 있습니다. 한 줄(배열)이 한 문제의 보기 4개입니다.
- `web/voice/index.json`(`{"글자": "voice/파일.mp3"}`)과 음성 파일이 있으면 기기 음성(TTS) 대신 그 파일을 씁니다. Claude 앱 화면처럼 기기 음성이 없는 곳에서도 소리가 나게 하려면 필요합니다.
- 음성은 **MeloTTS(MIT 라이선스 오픈소스)**로 만듭니다. 키가 필요 없어서 `web/content.js`를 고친 PR마다 GitHub Actions(`음성 파일 만들기`)가 새 문항만 만들어 그 PR 브랜치에 커밋합니다. Actions 탭에서 직접 돌릴 수도 있습니다(`시험 삼아 앞의 몇 개만` 입력란으로 일부만 만들어 볼 수 있습니다).
- 만든 음성은 **Whisper로 다시 들어 확인**합니다. 받아 적은 말이 정답보다 같은 문제의 다른 보기(예: 쌀↔살)에 더 가깝게 들리면 빠르기와 조건을 바꿔 다시 만들고(짧은 낱말은 최대 8번), 그래도 애매하면 `tools/voice_qa.json`에 남기고 `index.json`에서 뺍니다(앱은 그 문항을 기기 음성이나 가족 목소리로 들려주고, 기기 음성이 없는 곳에서는 음성 파일이 있는 문항을 골라 냅니다). 한두 글자 낱말은 작은 Whisper 모델이 자주 잘못 받아 적어 큰 모델(medium)로 듣고, '3시'처럼 숫자로 적은 것은 '세 시'·'삼 시'로 읽어 견줍니다. Actions에서 `애매했던 음성도 다시 만들기`를 켜고 돌리면 애매했던 것만 새 시드로 다시 만들고, 전보다 나을 때만 바꿉니다. 지금은 573개 중 547개가 확인을 통과했습니다.
- 저장소 Settings > Secrets and variables > Actions에 `AZURE_SPEECH_KEY`와 `AZURE_SPEECH_REGION`(예: `koreacentral`)을 넣어 두면 대신 **Azure 음성 서비스(공식 API, 한국어 SunHi 음성)**를 씁니다.
- 직접 만들려면 `pip install git+https://github.com/myshell-ai/MeloTTS.git faster-whisper lameenc && python -m unidic download` 뒤에 `python3 tools/make_voices.py`(node 필요). Azure로 만들려면 `AZURE_SPEECH_KEY=... AZURE_SPEECH_REGION=koreacentral python3 tools/make_voices.py --engine azure`(무료 F0 요금제는 1분에 20번까지라 전체를 처음 만들 때 30분쯤 걸립니다).
- 파일 수 제한이 있는 곳(예: Claude 아티팩트)에 올릴 때는 `python3 tools/make_sprites.py OUT`으로 음성을 묶음 몇 개로 합칩니다(ffmpeg 필요). 앱은 index.json 값이 객체(`{s, t, d}`)면 묶음의 해당 구간을 재생합니다.
