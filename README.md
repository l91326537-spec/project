# 소리길: 게임형 청각 재활 앱

인공와우·보청기 사용자가 집에서 매일 하는 청능훈련을 게임으로 만들고, 치료사가 원격으로 진도를 보는 앱입니다. 경진대회 출품용 시제품입니다.

## 실행
온라인 주소: https://l91326537-spec.github.io/project/ (main에 병합하면 자동 배포, 휴대폰에서 홈 화면에 추가 가능)

설치나 서버 없이 `web/index.html`을 브라우저로 열면 됩니다. 마이크 녹음은 `https://` 또는 `localhost`에서만 동작하므로, 로컬에서는 아래처럼 띄우는 걸 권장합니다.

```
cd web && python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 지금 되는 것
- **1단계 소리 감지**: 500~4000Hz 순음. 맞히면 5dB씩 작게, 놓치면 크게(적응형). 4번 중 1번은 소리 없음(찍기 방지).
- **2단계 환경음**: 초인종·전화벨·경적·사이렌 등 8가지 생활 소리를 합성해 들려주고 고르기. 레벨에 따라 보기 2→4개.
- **3단계 단어**: 글자 수가 다른 단어 → 같은 길이 단어 → 최소대립쌍(살/쌀, 불/풀/뿔) 순으로 어려워짐. 단어 242개(75묶음).
- **5단계 문장**: 생활 문장 157개 + 낱말 고르기 20틀. 서로 다른 생활 문장 → 한 낱말만 다른 문장 → 문장 속 헷갈리는 낱말 고르기(취약음 분석에 반영). 문장도 가족 목소리로 녹음할 수 있음.
- **6단계 소음 속 듣기**: 식당·카페·버스·병원 대기실 소음(여러 사람 말소리, 그릇 소리, 엔진 소리 등)을 합성해 깔고 그곳에서 듣는 문장 96개를 들려줌. 레벨이 오를수록 소음이 커짐(말소리 대 소음 +12 → +6 → +2dB). 틀리면 소음 없이 정답을 다시 들려줌.
- **가족 목소리**: 가족이 단어·문장을 녹음하면 그 목소리로 출제(없으면 AI 음성이나 기기 음성).
- **취약음 분석과 맞춤 출제**: 틀린 답을 자모 단위로 비교해 "첫소리 ㅅ↔ㅆ"처럼 헷갈린 소리를 집계하고, 3·5단계에서 그 소리가 든 문제를 10문제 중 6문제쯤 더 자주 냄(문제에 '맞춤 문제' 표시). 맞춤 문제를 맞힐수록 그 소리는 덜 나옴.
- **치료사·보호자 리포트**: 기록 화면에서 한 장짜리 리포트(연습한 날, 단계별 처음→최근 정답률, 자주 헷갈린 소리와 맞춤 문제 정답률, 높낮이별 결과, 메모). A4 한 장으로 인쇄·PDF 저장.
- **따라 말하기**: 들은 말을 소리 내어 따라 하면 음성 인식 결과를 자모 단위로 비교해 일치도(%)와 다르게 들린 소리(예: 첫소리 ㅅ↔ㅆ)를 보여 줌. 쉬운 단어·헷갈리는 단어(약한 소리 맞춤)·생활 문장. 크롬·사파리에서 동작하고, 음성 인식이 없는 브라우저(삼성 인터넷 등)는 녹음해서 정답과 나란히 들어 보는 방식. 결과는 리포트에도 들어감.
- **시연용 예시 기록**: 기록 화면에서 2주 동안 쓴 것처럼 기록을 채우고, 끄면 원래 기록으로 돌아감.
- **자동 난이도**: 한 판 정답률 80% 이상이면 레벨 업, 50% 미만이면 다운.
- **점수·연속기록·14일 그래프**, 기록 JSON 내보내기(치료사 공유용).

기록과 녹음은 모두 사용자 기기(localStorage, IndexedDB)에만 저장됩니다.

## 문항과 음성
- 문항은 `web/content.js`에 모여 있습니다. 한 줄(배열)이 한 문제의 보기 4개입니다.
- `web/voice/index.json`(`{"글자": "voice/파일.mp3"}`)과 음성 파일이 있으면 기기 음성(TTS) 대신 그 파일을 씁니다. Claude 앱 화면처럼 기기 음성이 없는 곳에서도 소리가 나게 하려면 필요합니다.
- 음성은 **MeloTTS(MIT 라이선스 오픈소스)**로 만듭니다. 키가 필요 없어서 `web/content.js`를 고친 PR마다 GitHub Actions(`음성 파일 만들기`)가 새 문항만 만들어 그 PR 브랜치에 커밋합니다. Actions 탭에서 직접 돌릴 수도 있습니다(`시험 삼아 앞의 몇 개만` 입력란으로 일부만 만들어 볼 수 있습니다).
- 만든 음성은 **Whisper로 다시 들어 확인**합니다. 받아 적은 말이 정답보다 같은 문제의 다른 보기(예: 쌀↔살)에 더 가깝게 들리면 빠르기와 조건을 바꿔 다시 만들고(짧은 낱말은 최대 8번), 그래도 애매하면 `tools/voice_qa.json`에 남겨 로그에 알립니다. 한두 글자 낱말은 작은 Whisper 모델이 자주 잘못 받아 적어 큰 모델(medium)로 듣고, '3시'처럼 숫자로 적은 것은 '세 시'·'삼 시'로 읽어 견줍니다. Actions에서 `애매했던 음성도 다시 만들기`를 켜고 돌리면 애매했던 것만 다시 만듭니다.
- 저장소 Settings > Secrets and variables > Actions에 `AZURE_SPEECH_KEY`와 `AZURE_SPEECH_REGION`(예: `koreacentral`)을 넣어 두면 대신 **Azure 음성 서비스(공식 API, 한국어 SunHi 음성)**를 씁니다.
- 직접 만들려면 `pip install git+https://github.com/myshell-ai/MeloTTS.git faster-whisper lameenc && python -m unidic download` 뒤에 `python3 tools/make_voices.py`(node 필요). Azure로 만들려면 `AZURE_SPEECH_KEY=... AZURE_SPEECH_REGION=koreacentral python3 tools/make_voices.py --engine azure`(무료 F0 요금제는 1분에 20번까지라 전체를 처음 만들 때 30분쯤 걸립니다).
- 파일 수 제한이 있는 곳(예: Claude 아티팩트)에 올릴 때는 `python3 tools/make_sprites.py OUT`으로 음성을 묶음 몇 개로 합칩니다(ffmpeg 필요). 앱은 index.json 값이 객체(`{s, t, d}`)면 묶음의 해당 구간을 재생합니다.
