# 소리길: 게임형 청각 재활 앱

인공와우·보청기 사용자가 집에서 매일 하는 청능훈련을 게임으로 만들고, 치료사가 원격으로 진도를 보는 앱입니다. 경진대회 출품용 시제품입니다.

## 실행
설치나 서버 없이 `web/index.html`을 브라우저로 열면 됩니다. 마이크 녹음은 `https://` 또는 `localhost`에서만 동작하므로, 로컬에서는 아래처럼 띄우는 걸 권장합니다.

```
cd web && python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 지금 되는 것
- **1단계 소리 감지**: 500~4000Hz 순음. 맞히면 5dB씩 작게, 놓치면 크게(적응형). 4번 중 1번은 소리 없음(찍기 방지).
- **2단계 환경음**: 초인종·전화벨·경적·사이렌 등 8가지 생활 소리를 합성해 들려주고 고르기. 레벨에 따라 보기 2→4개.
- **3단계 단어**: 글자 수가 다른 단어 → 같은 길이 단어 → 최소대립쌍(살/쌀, 불/풀/뿔) 순으로 어려워짐.
- **가족 목소리**: 가족이 단어를 녹음하면 3단계에서 그 목소리로 출제(없으면 한국어 TTS).
- **취약음 분석(규칙 기반 1차)**: 틀린 답을 자모 단위로 비교해 "초성 ㅅ↔ㅆ"처럼 헷갈린 소리를 집계.
- **자동 난이도**: 한 판 정답률 80% 이상이면 레벨 업, 50% 미만이면 다운.
- **점수·연속기록·14일 그래프**, 기록 JSON 내보내기(치료사 공유용).

기록과 녹음은 모두 사용자 기기(localStorage, IndexedDB)에만 저장됩니다.
